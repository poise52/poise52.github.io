# Egor Mullayarov — Portfolio

Static English-language portfolio for https://amaecp.xyz/.

## Publish

In Settings → Pages, select Deploy from a branch, main, / (root). Set the custom domain to amaecp.xyz and enable HTTPS when its certificate is ready. No build step is required.

## Edit

Update index.html, style.css or script.js and push to main. GitHub Pages publishes the changes automatically.
